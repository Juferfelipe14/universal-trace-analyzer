Input · S11/S5 capture (MME ↔ SGW ↔ PGW)

New data sessions keep failing

Create Session Request APN internet Create Session Response 84 All dynamic addresses occupied

Not the subscriber and not the radio: the gateway's IP pool for that APN is full, so every new session fails until addresses are freed or the pool grows.

Input · test-system report (PDF, two test phones)

VoLTE MO→MT test failed

PTC_B TCP → P-CSCF :5060 timeout PTC_A REGISTER → 503

Two separate problems, not one: PTC_B never reached its P-CSCF, while PTC_A was refused by the IMS. Each gets its own next step.

Input · phone-side L3 log (uplink only)

Call never answered

INVITE branch=…7d1c ACK branch=…7d1c same branch

The answer isn't in a phone log, but the phone's ACK reuses the INVITE branch, so per RFC 3261 the call got a final error response.
